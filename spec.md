Iron Altar

Strength training tracker app with a heavy metal/Greek mythology theme based on the legend of Milo of Croton

Aesthetic is eight bit pixel art RPG game

Basic concept is strength training, tracker app that records your workouts and provides data visualization

Create your profile and pick an avatar that starts out skinny and must be fed like a Tamagotchi by doing workouts and gets bigger and stronger overtime

Gamifies strength training

Constraints

- Must be able to run on iOS and Android
- Must be able to run on web browser

User Experience

Landing Page - Dungeon Gym
User Profile - Avatar + stats
Workout History - summarized past workouts list
Data Visualization - graphs of progress for each main lift + body weight
Session Log - page for using during a workout to log sets + reps + notes
Set completion animation - congratulatory animation upon logging a set
Workout complete animation - animation upon completing a workout, avatar grows a little bigger
